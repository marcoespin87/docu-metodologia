# Índice de Specs

Este directorio contiene los documentos vivos que describen el comportamiento real (*as-built*) del sistema.

Este proyecto viene de un Caso 5 (código heredado sin documentación previa): las capacidades se van agregando a este índice a medida que se completa su Fase 0, una por vez. Que una capacidad no esté todavía en esta tabla no significa que no exista en el código — significa que todavía no pasó por la ingeniería inversa de especificación.
